**TL;DR**：Claude Code 有几十个命令，但前两周只需要掌握 8 个。这篇文章按优先级排，学完这 8 个，你的使用效率会比默认用法高出一个量级。

<!-- more -->

## 上下文是你最稀缺的资源，先学会管理它

Claude Code 的每个会话有上下文限制。大多数新用户不知道这件事，直到某次对话突然变慢、变蠢，才意识到上下文快满了。

**`/compact`**：把当前对话压缩成摘要，释放上下文空间。适合在一个会话里干了很多事之后用。压缩后 Claude 仍然知道"做了什么"，但不再逐字记住每一轮对话。

**`/context`**：查看当前上下文的健康状态——已用多少、剩多少。建议在开始一个新的大任务之前先看一眼。

**`CLAUDE.md`**：项目根目录放一个 `CLAUDE.md` 文件，里面写项目背景、编码规范、常用路径。Claude Code 每次启动会自动读取。这相当于给 Claude 的"永久记忆"——不占用对话上下文，但每次都生效。

如果你的项目还没有 `CLAUDE.md`，现在就创建一个。这是单个操作里 ROI 最高的。

## 问一个临时问题，不要污染正在进行的任务

你正在让 Claude 帮你重构一个函数，突然想问它"这个 API 的参数是什么格式"。如果直接问，这个问题会进入上下文，干扰后续的任务理解。

**`/btw`**：临时提问，不进入主对话上下文。问完即走，不留痕迹。

用法：`/btw 这个函数的时间复杂度是多少？`

这个命令用得好，可以让主对话保持干净、聚焦。

---

## 改坏了？两步回到之前的状态

写代码难免走错方向。Claude Code 改了一堆文件之后，你发现思路不对，想撤回。

**`/rewind`**（或双击 Esc）：回退代码和对话。有 4 个选项：
- 回退到上一步操作
- 回退到某一个检查点
- 只回退代码，保留对话
- 只回退对话，保留代码

第三个选项特别有用：Claude 改了代码，但你想保留改动，只是想重新解释一遍需求。

---

## 不确定怎么做时，先让它规划，再让它执行

新用户常见的错误：直接说"帮我实现 XXX 功能"，然后 Claude 开始动文件，改到一半你发现方向不对。

**`/plan`**：让 Claude 先输出实现计划，不动任何文件。你确认计划没问题之后，再开始执行。

对于复杂任务，这一步能避免大量无效的来回。计划阶段发现问题，比执行到一半发现问题便宜得多。

---

## Pro 用户：用 Opus 规划，用 Sonnet 执行，省钱又提速

如果你是 Claude Pro 用户，有两个模型可以用：Opus（更强，更慢，更贵）和 Sonnet（更快，更便宜）。

**`/model opusplan`**：规划阶段用 Opus，执行阶段自动切换到 Sonnet。这是官方推荐的用法，在任务复杂度和成本之间取得平衡。

如果你没有 Pro，跳过这条。

---

## 同一个问题，想探索两种不同方案

你在让 Claude 设计一个接口，走到一半，想试试另一个思路，但不想丢掉现在的进展。

**`/branch`**：从当前会话分叉出一个新的会话，两条线互不干扰。你可以在分叉里探索另一个方案，然后决定用哪个。

这比"开一个新会话、重新粘贴上下文"省事很多。

---

## 关掉终端之后，任务还在跑

**`Ctrl+B`**：把当前任务放到后台执行。你可以关掉终端，去干别的事。任务完成后会通知你。

适合耗时较长的任务：生成大量文件、跑测试、做批量重构。不适合需要你实时反馈的交互式任务。

---

## 昨天的会话，今天还能接着用

Claude Code 的会话默认是临时的，关掉就没了。但有几个命令可以管理会话生命周期：

- **`/rename`**：给当前会话起一个名字，方便之后找到它
- **`/resume`**：列出历史会话，选择恢复哪一个
- **`/continue`**：直接恢复最近一次会话

如果你在做一个持续几天的任务（比如开发一个新功能），`/rename` + `/resume` 的组合可以让你每天接着昨天的进度继续，不用重新解释背景。

## 快速参考

| 场景 | 命令 |
|---|---|
| 上下文快满了 | `/compact` |
| 查看上下文剩余量 | `/context` |
| 临时提问不污染对话 | `/btw` |
| 撤回代码或对话 | `/rewind` 或双击 Esc |
| 先规划后执行 | `/plan` |
| 规划用 Opus，执行用 Sonnet | `/model opusplan` |
| 探索不同方案 | `/branch` |
| 任务后台化 | `Ctrl+B` |
| 恢复历史会话 | `/resume` |

---

## 接下来学什么

掌握这 8 个功能之后，下一步可以看：

- **`CLAUDE.md` 进阶**：团队共享配置、多层级配置文件
- **Hooks 钩子**：在 Claude 每次操作前后自动触发脚本（比如自动跑测试）
- **`/permissions`**：精细控制 Claude 可以读写哪些文件
- **MCP（Model Context Protocol）**：接入外部工具和数据源

但这些都是之后的事。现在，先把 `CLAUDE.md` 创建起来。
